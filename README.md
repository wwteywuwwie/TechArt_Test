# TechArt Test: боевой VFX и сумеречное освещение (Unity 6 HDRP)

Тестовое задание на позицию Technical Artist. Персонаж от третьего лица наносит удары мечом по мишени и получает мгновенную визуальную и пространственную обратную связь.

*   **Версия Unity:** 6000.3.27f1 (Unity 6.3 LTS, HDRP)
*   **Сцена:** Assets/Project/Scenes/Arena.unity
*   **Репозиторий:** [https://github.com/wwteywuwwie/TechArt\_Test](https://github.com/wwteywuwwie/TechArt_Test)
*   **Билд (Windows Standalone):** [https://cloud.mail.ru/public/ug9v/eh2gB8GXi](https://cloud.mail.ru/public/ug9v/eh2gB8GXi)

## 1\. Управление и сценарий воспроизведения эффектов

### Управление

| Действие | Клавиша |
| --- | --- |
| Перемещение | WASD |
| Вращение камеры | Мышь |
| Прыжок / Спринт | Space |
| Удар мечом | ЛКМ |
| Замер производительности (30 секунд) | F9 |

### Сценарий воспроизведения

1.  Запустить TechArt\_Test.exe, подойти к мишени Target\_Dummy (состояние «готова»).
2.  Нажать **ЛКМ**: клинок делает процедурный замах, оставляя на клинке видимый след (Trail Renderer).
3.  В момент касания клинка с мишенью: короткая пауза клинка (hit pause), вспышка в точке контакта, искры, кратковременный динамический свет.
4.  На мишени в точке удара растворяется дыра с горящей кромкой (состояние «получила попадание»).
5.  Примерно через 4 секунды дыра затягивается (состояние «восстановилась»).
6.  Повторный удар переносит дыру в новую точку.

### Покрытие требований ТЗ

| Требование ТЗ | Реализация в проекте |
| --- | --- |
| След (contact cue) | Trail Renderer на клинке меча |
| Вспышка контакта | VFX_Impact (Flash) |
| Вторичные частицы | VFX_Impact (Sparks) |
| Decal / Реакция материала | Растворение мишени в Shader Graph SG_TargetDissolve |

*Эффект появляется в точке реального касания клинка с мишенью, а не в фиксированном месте.*

## 3\. Shader Graph (SG\_TargetDissolve)

Параметризованный шейдер содержит следующие свойства:

| Свойство | Тип | По умолчанию | Смысл |
| --- | --- | --- | --- |
| Base Color | Color | #3A3A3A | Цвет мишени |
| Dissolve Amount | Float (0–1) | 0 | Степень глобального растворения |
| Noise Scale | Float | 8 | Размер шума маски |
| Edge Width | Float (0.01–0.2) | 0.05 | Ширина светящейся кромки |
| Edge Emission Color | Color | Тёплый оранжевый | Цвет кромки |
| Emission Intensity | Float | 1000 | Яркость HDR-эмиссии |
| Hit Position | Vector3 | (0, 0, 0) | Точка удара в мировом пространстве (world space) |
| Hit Radius | Float | 1 | Радиус зоны поражения |

**Реализованные признаки ТЗ:**

1.  **Маска растворения:** Комбинация Simple Noise и параметра Dissolve Amount.
2.  **Управляемая эмиссия:** Задаётся через Edge Emission Color с умножением на Emission Intensity.
3.  **World-Space модуляция:** Вычисление расстояния от позиции пикселя в мировых координатах до Hit Position, нормированное на Hit Radius.

## 4\. Освещение HDRP и инженерные решения

### Настройка освещения

*   **Ключевой:** Directional Light, низкое тёплое солнце, 4000 лк, режим Mixed.
*   **Заполняющий:** Light\_Fill, холодный Directional сверху, 9000 лк, тени выключены.
*   **Контровой:** Light\_Rim, слабый холодный Directional с противоположной стороны, тени выключены.
*   **Динамический свет события:** точечный свет в VFX\_Impact.
*   **Light Probes:** APV\_Arena (Adaptive Probe Volume), запечён.
*   **Reflection Probe:** ReflectionProbe\_Arena, режим Baked.
*   **Global Volume:** Fixed Exposure 10, Tonemapping ACES, Color Adjustments (Contrast 10, Saturation -5), Bloom (Threshold 1, Intensity 0.25, Scatter 0.5).

### Аргументация инженерных выборов

1.  **Object Pooling (ImpactVfxPool):** Устраняет скачки сборщика мусора (GC) во время динамического боя за счет предзагрузки эффектов.
2.  **Единая точка поражения (Hit Position в Shader Graph):** Избегает лишних Draw Calls от декалей и перегрузки шейдеров массивами, сохраняя идеальную производительность.
3.  **Смешанное освещение (Mixed + APV):** Разгружает рендер за счет запекания непрямого света и отключения теневых пассов на вспомогательных источниках.
4.  **Процедурная хит-пауза (Hit Pause):** Добавляет оружию физический «вес» и улучшает читаемость импакта.

## 6\. Оптимизации и известные ограничения

### Применённые решения

*   Смешанная схема освещения (запеченный непрямой свет APV + динамический свет удара).
*   Заполняющий и контровой свет без просчета теней.
*   Растворение мишени реализовано единым параметризованным шейдером с одной точкой удара без накопления объектов.
*   Короткоживущие эффекты и быстрый затухающий свет.
*   Умеренный Bloom, не разрушающий форму частиц.
*   Отсутствие трассировки лучей (Ray Tracing).
*   Качество фильтрации теней направленного света снижено с High до Medium: убирает шум по краям теней и дешевле по кадру. Тени включены только у солнца (Angular Diameter 0.5).

### Ограничения и компромиссы

*   Одна активная дыра на мишень: повторный удар переносит её в новую точку (экономия ресурсов в пользу отказа от декалей).
*   Фиксированная экспозиция (10) для стабильной яркости при вспышках VFX.
*   Окружение и герой из примитивов и Starter Assets (PBR-текстуры не используются).
*   Статичная мишень без анимации.
